System Design

Subsystem Architecture

⚡
FaultDetector
health/FaultDetector.cpp
Evaluates every TelemetryFrame against SatelliteConfig thresholds. Fires a typed FaultEvent callback for battery, thermal, CPU, and memory violations. Stateless per-frame; zero heap allocation in the hot path.
callback pattern zero-alloc threshold engine
📡
TelemetryDispatcher
telemetry/TelemetryDispatcher.cpp
Background thread drains a mutex-protected TelemetryFrame queue, serializes each frame to JSON, and sends over UDP to the ground station. Tracks frames sent and dropped via atomics.
UDP socket std::thread lock-guard
📋
CommandDeserializer
serialization/CommandDeserializer.cpp
Parses uplink JSON into typed Command structs with opcode validation against an allowlist. Throws std::invalid_argument for unknown opcodes; std::runtime_error on malformed input.
JSON parsing opcode allowlist exception safety
🗂
CommandQueue
command/CommandQueue.cpp
Thread-safe bounded FIFO with condition_variable–based popWait(). Separate push / tryPop / popWait interface covers polling and blocking consumers with a configurable depth cap.
std::mutex condition_variable bounded queue
🔀
CommandHandler
command/CommandHandler.cpp
Opcode-keyed dispatch table mapping Opcode → std::function callback. dispatchRaw() chains deserialization → dispatch in one call, returning typed CommandResult for each outcome.
dispatch table std::function unordered_map
⚙️
ConfigLoader
serialization/ConfigLoader.cpp
Reads satellite.yaml at startup into a SatelliteConfig struct. Validates critical invariants (voltage min < max, non-empty IP). Provides safe defaults for all optional fields.
yaml-cpp validation defaults
